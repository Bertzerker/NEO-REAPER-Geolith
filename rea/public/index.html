Bounded input experiment
Bits: Up 1, Down 2, Left 4, Right 8, A 16, B 32, C 64, D 128, Start 256, AES Select / MVS Coin 512. Keyboard: arrows, Z/X/A/S, Enter/Shift. Unspecified inputs are released during experiments. Pause interrupts at a completed frame.
Instruction trace, access watchpoints, game collisions, fetch chains, timeline editing, service inputs, CD and retail special-board validation are unavailable. Sound emulation runs; audio playback is not implemented.
