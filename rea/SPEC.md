# Delivered contract — NEO REAPER - Geolith

Protocol 1, Windows x64/.NET 10/MSVC. Core pinned to `2dc88e3fa72ff404213a65d6eb5bb33baa687f73`. Source builds do not change the upstream checkout: exact-anchor patches are applied in ignored `rea/obj/native`. Capture observes one ordinary Geolith render; no layer toggling or repeated emulation synthesizes views.

Evidence IDs are session UUID + monotonic sequence; emulated frame and restore generation are separate. The normal native buffer is 320×264; all UI/API images use x=8, y=24, 304×224. Geolith renders lines 8–247; a complete capture checks every visible row. Final conversion uses Geolith resistor-network palette. Sprite samples preserve the palette/color/object/tile of the last admitted nonzero sprite pixel before FIX. A sprite obscured by another sprite is not retained; a sprite under FIX is retained. FIX samples are recorded at its actual write, including upstream bank paths if reached. Default-board configuration exercises unbanked FIX; special NGH boards requiring other paths remain unsupported. Compositor winner is captured as backdrop/sprite/FIX. Boundary memory cannot establish earlier fetch contents; pixel fields say unavailable for unrecorded provenance.

Native state comes from upstream serialization plus explicit extensions for sprite line buffers, active buffer, palette pointer reconstruction, sound resampler/FM preparation/cache scheduling, pointer-free Musashi CPU execution context and latched pad state. The host adds frame/configuration identity and restores held frontend pads. Callback/code/data pointers are not exported. State is exact-build and architecture specific. Original diagnostic tests cover CPU, active Z80/SSG, RTC serialization, input, raster palette changes, replay and observer equality. They do not certify all possible game/device state paths.

One thread owns every core call. HTTP commands enter a bounded 16-item queue. Bounded steps execute 1–3600 complete `geo_exec` boundaries; pause sets cancellation immediately and reconciles through the owner. Normal play is paced at the selected core's AES 59.599484 Hz or MVS 59.185606 Hz times speed. Inputs latch at the beginning of each `geo_exec`; unspecified experiment masks are zero. Browser keyboard is optional/focus scoped. Read-only movie rows override supplied step masks; live-pad mutation is rejected. Movie state, video and generated audio hashes are checked every row. Reset/service/configuration/topology controls do not exist and cannot occur through the movie interface. Recording is bounded to 36000 rows; no timeline edit/seek is claimed.

Captures copy native output, two planes, recorded sample metadata, registers and eight memory buffers at the completed frame boundary. VRAM/palette words are converted from native little-endian storage to big-endian word bytes. Normal playback copies every fourth completed frame; explicit stepping captures the last completed frame. Eight captures plus eight finite 120-second leases bound memory retention. Archives are disk-backed. The implementation currently allocates capture arrays rather than using a reusable pool; this is a documented optimization backlog. Encoding/network/file operations use detached data off the emulation thread except checkpoint/movie persistence commands. WebSocket clients have one send in flight, two-second send timeout, latest-only capture choice and a four-client limit. Hidden/frozen pages discard streaming messages without decoding/uploading. One persistent WebGL texture receives one lossless synchronized atlas upload per presentation.

Comments archive immutable evidence before the note commit, preserve revision checks and browser recovery, and render local Markdown/JSON/Mermaid with sanitization and strict diagrams. Saved review has no core call. Checkpoint restore has no implicit saved-review navigation. Bundles contain identities, native evidence/memory, images, note revisions and a matching immutable saved movie where linked, with a manifest verifiable offline. ROM/firmware bytes are excluded by construction. Original test fixtures and private session evidence remain separate; only the diagnostic generator/source is committed.

Loopback-only API validates Host, Origin, token, body sizes, finite IDs/ranges and static paths. Mutations require POST JSON. Unknown/unsupported actions are rejected. No arbitrary filesystem reads, imports, execution, firmware download or publication routes exist. Assets/states are trusted local emulator inputs, not a hostile-code sandbox. See README for actual routes; unsupported endpoints are not advertised.

## Explicit remaining work

- Retail compatibility is title/configuration specific: supplied Metal Slug is validated in US MVS mode, while commercial AES remains unverified without an AES BIOS. Default-board cartridges are admitted; all special-case NGH/protection/alternate-controller/link paths are rejected. Validate relevant games and bounds before expanding this adapter. No commercial BIOS/ROMs were downloaded.
- Original fixture uses artificial identity vertical-zoom tables; full vertical zoom/hardware accuracy is not established. Horizontal zoom, chaining, overlap, clipping/wrapping, transparency and raster palette changes are exercised in the renderer. Fine raster behavior inherits Geolith's instruction-level timing limitations.
- Sound emulation, state and movie audio hashes work; audible playback and browser/native audio controls are unavailable.
- Instruction traces/access watchpoints, fetch chains, collision inference, NGP/CD/link/multi-slot and timeline editing remain unsupported. Source winner is recorded, but no separate source-map graphics card is currently shipped.
- Immutable P/S/M/V1/V2/C bytes are available on demand for the currently verified identity, in physical file storage order. Archived investigations omit these asset bytes and require matching local assets for those reads. No large assets are recopied into every capture.
- Pool capture buffers; share atlas encoding among viewers; expose more granular queue/drop/capture-cost counters. Renderer observer-only timings and actual host/stream cadence are measured separately.
- Exact 390×844 mobile layout is validated. 200% visual viewport zoom is validated; true desktop browser 200% zoom/reflow remains unverified. Accessibility is not certified.

This is a native diagnostic-backed integration with a usable workbench, not certification of commercial Neo Geo compatibility or universal determinism.
